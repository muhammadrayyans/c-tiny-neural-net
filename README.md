# Neural Network in C

A personal learning project focused on understanding how Artificial Neural Networks work internally by implementing them from scratch using the C programming language.

## About

Most modern AI applications are built using powerful frameworks such as TensorFlow and PyTorch. While these tools make development easier, they often hide the mathematical and computational foundations behind neural networks.

This project takes the opposite approach.

The goal is to build every fundamental component manually, starting from a single artificial neuron and gradually progressing toward a fully trainable Multi-Layer Perceptron (MLP). The focus is on learning and understanding rather than using pre-built machine learning libraries.

## Learning Objectives

* Understand how artificial neurons work
* Learn the purpose of weights and biases
* Implement activation functions
* Explore learning rates and training loops
* Understand forward propagation
* Implement Multi-Layer Perceptron architecture
* Learn loss calculation and optimization
* Implement backpropagation from scratch
* Build a complete trainable neural network in C

## Current Status

The project currently includes a working perceptron implementation, dataset-based training, and a manually built Multi-Layer Perceptron architecture. Development is focused on understanding the mathematics and algorithms behind neural networks before moving to advanced learning techniques.

## Why This Project?

The objective is not simply to use Artificial Intelligence, but to understand how it works internally. By building neural network components from scratch, this project provides a strong foundation for studying Machine Learning, Deep Learning, and modern AI systems.
